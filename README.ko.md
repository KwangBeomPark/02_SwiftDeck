## SwiftDeck은 무엇을 하나요?

**SwiftDeck**은 자주 쓰는 폴더 이동, 반복 텍스트 입력, 프롬프트 실행, 단축어 자동완성, 키 리매핑, 프롬프트 팝업 메뉴 기능을 하나의 Windows 트레이 앱으로 통합한 업무 자동화 도구입니다.

재무, 회계, 채권, 영업관리, 백오피스 조직처럼 ERP, 월말 결산 폴더, 공유 드라이브, 반복 이메일, 정형 문구를 자주 사용하는 팀에 특히 적합합니다.

> **월말 결산 가속화 · 휴먼 에러 방지 · 반복 업무 축소 · 업무 방식 표준화**

---

## 핵심 기능 요약

- **📂 폴더 원클릭 이동**: 자주 쓰는 폴더, ERP 다운로드 경로, 월별 증빙 폴더, 공유 네트워크 드라이브를 단축키 메뉴로 즉시 엽니다. 2단계 하위 폴더 탐색과 지능형 캐시를 지원합니다.
- **⌨️ 프롬프트 및 SQL 텍스트 자동화**: 긴 텍스트, SQL 쿼리, AI 프롬프트, `{Enter}` · `{Tab}` · `{Wait:500}` · `{Ctrl+S}` 같은 제어키 시퀀스를 실행합니다.
- **📋 프롬프트 팝업 메뉴**: `Shift + Win + Space`를 누르면 마우스 커서 위치에 등록된 모든 프롬프트가 팝업 메뉴로 표시됩니다. 슬롯 번호를 외우지 않아도 클릭 한 번으로 즉시 실행할 수 있습니다.
- **✏️ 단축어 자동완성**: 짧은 지정어를 이메일 템플릿, 보고 문구, 특수기호, 표준 메시지로 즉시 확장합니다. Space 또는 Enter 입력 후 자동 치환됩니다.
- **🔀 키 리매핑**: CapsLock처럼 거의 쓰지 않는 키를 실무용 단축키, 마우스 클릭, 반복 동작으로 변경합니다.
- **⚙️ 포터블 팀 배포**: 로컬 `.ini` 설정 파일을 공유하여 팀 공통 폴더, 프롬프트, 템플릿을 표준화할 수 있습니다. 설치 불필요.

## 🚀 다운로드 및 실행 방법

**SwiftDeck**은 별도 설치 없이 실행 파일을 더블 클릭하여 사용하는 **무설치 포터블 프로그램**입니다.

### 📥 일반 팀원용 원클릭 다운로드

1. 깃허브 화면 우측의 **[Releases](https://github.com/KwangBeomPark/02_SwiftDeck/releases)** 탭으로 이동합니다.
2. 최신 릴리즈의 **`SwiftDeck.vX.Y.Z.zip`** 또는 **`SwiftDeck.vX.Y.Z.exe`** 단독 실행 파일을 다운로드합니다. (예: `SwiftDeck.v1.3.2.exe`)
3. 필요한 경우 압축을 풀고 내려받은 `.exe`를 더블 클릭합니다.
   각 릴리즈에는 내용이 같은 `SwiftDeck.exe`도 함께 올라갑니다. v1.3.1 이하 버전의 자동 업데이트가 이 이름을 사용합니다.
4. Windows 우측 하단 시스템 트레이에 검은색 번개 아이콘이 표시되면 바로 사용할 수 있습니다.

아직 릴리즈 파일이 등록되지 않은 경우, AutoHotkey v2로 `src/SwiftDeck.ahk`를 직접 실행하거나 빌드해 주세요.

### 🔄 자동 업데이트

SwiftDeck은 시작 후 하루에 최대 한 번 GitHub의 최신 정식 릴리스를 확인합니다. 새 릴리스가 있으면 **App Settings** 헤더에 `New version vX available`을 표시하고 헤더의 **Update to vX** 버튼에서 바로 검증된 업데이트를 시작할 수 있습니다. **App Information**과 트레이 메뉴의 **Check for Updates**에서는 수동으로 다시 확인할 수 있습니다. 업데이트는 현재 실행 파일과 같은 폴더에 릴리스 실행 파일을 내려받고 `SwiftDeck.update.ini`의 SHA-256을 확인한 뒤 안전하게 교체하고 재실행합니다. 버전이 표기된 자산을 우선 사용하고 없으면 `SwiftDeck.exe`로 대체합니다. 실행 중인 파일의 이름은 그대로 유지되므로, 이름을 바꿔 쓰던 실행 파일은 업데이트 후에도 그 이름을 유지합니다. `%AppData%\SwiftDeck`의 저장 설정은 교체하지 않습니다. 소스 실행 모드와 읽기 전용 폴더에서는 수동 업데이트만 제공합니다.

### 🛠️ 파워 유저 및 개발자용 커스텀 빌드

1. [AutoHotkey v2](https://www.autohotkey.com/)를 설치합니다.
2. 이 저장소를 Clone합니다.
3. `src/SwiftDeck.ahk` 소스 코드를 필요에 맞게 수정합니다.
4. AutoHotkey에 포함된 Ahk2Exe 도구를 사용하여 본인만의 `SwiftDeck.exe`를 `dist/`에 패키징합니다.

### 저장소 구조

```text
src/      앱 진입점과 AutoHotkey 라이브러리 소스
assets/   공개 이미지, 아이콘, README 미디어
dist/     .exe, .zip 같은 로컬 릴리즈 산출물, Git 제외
```

배포용 바이너리는 저장소 본문에 커밋하지 않고 GitHub Releases에 업로드합니다.

## 💼 재무/FinOps 실무 활용 예시

- **월말 결산 폴더 접근**: `F1`을 눌러 월말 결산 폴더, ERP 다운로드 폴더, 증빙 파일, 공유 드라이브 메뉴를 한 번에 엽니다.
- **SQL / AI 프롬프트 실행**: 단축키를 누르거나 프롬프트 팝업 메뉴(`Shift + Win + Space`)를 열어 긴 SQL 쿼리나 자주 쓰는 AI 프롬프트를 자동 입력합니다.
- **표준 이메일 템플릿 입력**: `;t1` 같은 지정어를 입력하면 자금 일보, 예산 실적 조정 요청, 보고 문구가 자동 확장됩니다.
- **프롬프트 팝업 활용**: 슬롯별로 정리된 AI 프롬프트 라이브러리를 마우스 위치에서 팝업으로 탐색하고 실행합니다. 번호를 외울 필요가 없습니다.
- **입력 피로도 완화**: Excel, ERP, 복사/붙여넣기 업무에서 반복되는 키보드·마우스 작업을 줄여 손목 부담을 낮춥니다.
- **팀 업무 표준화**: 관리자가 공통 프롬프트, 폴더 경로, 단축어를 먼저 설정한 뒤 `.ini` 파일을 팀원에게 배포하면 별도 설정 없이 동일한 환경을 즉시 사용할 수 있습니다.

## 📖 사용자 매뉴얼

✔ **Folders**: 자주 찾는 폴더 경로 관리 및 단축 이동. 2단계 하위 폴더 탐색 지원.  
✔ **Prompts**: 반복 텍스트 및 `{Wait}` · `{Enter}` · `{Tab}` 같은 특수 제어키 매크로 수행. `{Ctrl+S}` · `{Alt+Tab}` 같은 단축키 조합도 실행 가능.  
✔ **Hotstrings**: 단축 텍스트 지정어 등록 및 Space · Enter 입력 후 즉각적인 자동완성.  
✔ **Key Remap**: 물리적 키를 더 유용한 단축키 또는 마우스 클릭으로 매핑.  
✔ **General**: 단축키, Windows 자동 시작, 설정 폴더, 저장된 설정 백업, 복원, 초기화를 한곳에서 관리.<br>
✔ **Folders**, **Prompts**, **Hotstrings**, **Key Remap**의 변경은 각 작업을 확인하는 즉시 저장·적용됩니다. 여러 단축키 값을 함께 조정하는 **General**만 **Save & Apply**를 유지하며, 미저장 General 변경이 있으면 닫기나 종료 시 **모두 저장**, **변경 버리기**, **계속 편집** 중에서 선택할 수 있습니다.

> **App Settings → Manual**에서 내장 안내서를 열 수 있습니다. 상단 단축키 요약은 현재 PC에 적용된 설정을 기준으로 자동 생성되며, 마지막으로 선택한 매뉴얼 언어를 다음에 다시 불러옵니다.

## ⌨️ 주요 단축키 및 컨트롤

| 단축키 | 기능 |
|--------|------|
| `F1` 기본값 | 어디서나 즐겨찾기 폴더 팝업 메뉴 열기 |
| `Win + Numpad (0~9)` | 등록된 프롬프트 슬롯 번호로 즉시 실행 |
| `Shift + Win + Space` | **프롬프트 팝업 메뉴**를 마우스 위치에서 열기 |
| `Ctrl + Win + Space` | 이모지 및 특수기호 선택기 열기 |

| `;지정어` 예: `;t1` | 짧은 단축어를 긴 텍스트 또는 이메일 템플릿으로 확장 |
| `시스템 트레이 메뉴` | 앱 설정 및 관리 메뉴 열기 |

## ⚙️ 설정 파일 및 팀 배포 방식

SwiftDeck 설정값은 모두 로컬 `.ini` 파일에 저장됩니다. 레지스트리를 사용하지 않습니다.

설정 파일 위치는 아래 메뉴에서 열 수 있습니다.

```text
시스템 트레이 메뉴 → Open Settings Folder
```

같은 기능은 **App Settings → General → Data, Startup & Recovery**에서도 사용할 수 있습니다.

- **Open Folder**: 로컬 설정 폴더를 엽니다.
- **Backup Saved**: 현재 디스크에 저장된 설정을 백업합니다. General에 미저장 표시가 있다면 먼저 적용하세요.
- **Restore**: 현재 설정을 교체하기 전에 확인한 뒤 SwiftDeck을 다시 로드합니다.
- **Factory Reset**: 백업은 보존하고, 확인 후 활성 설정을 기본값으로 교체합니다.

팀 배포 시에는 한 명의 관리자가 공통 폴더 경로, 프롬프트, 단축어를 먼저 세팅한 뒤 생성된 `.ini` 파일을 동료에게 공유하면 됩니다. 팀원은 파일을 지정된 위치에 넣고 앱을 재로드하면 즉시 동일한 환경을 사용할 수 있습니다.

## 🔐 보안 및 개인정보

- SwiftDeck은 Windows 로컬 환경에서 실행되며, 설정값은 사용자 PC에 저장되고 앱이 자동 동기화하지 않습니다.
- 내장 번역 기능을 사용할 경우, 사용자가 번역 대상으로 선택한 텍스트가 해당 요청에 한해 Google 공개 번역 엔드포인트로 전송됩니다.
- 번들된 지원 이미지가 없는 경우 Buy Me a Coffee 버튼, GitHub favicon 같은 공개 UI 자산을 다운로드할 수 있습니다.
- 폴더 경로, 프롬프트, 단축어, 키 리매핑 설정은 모두 로컬 `.ini` 파일에만 저장됩니다.
- **셸 인젝션 방어**: 등록된 폴더 경로는 실행 전 자동으로 검증됩니다. `&` · `|` · `>` · `<` 같은 OS 명령 연결 기호가 포함된 경로는 실행이 차단됩니다.
- 비밀번호, API Key, 개인 인증정보, 고도의 기밀정보는 Prompt 또는 Hotstring 설정에 저장하지 않는 것을 권장합니다.
- 팀원에게 `.ini` 파일을 공유하기 전에는 포함된 경로와 문구를 반드시 검토하세요.

## 👨‍💼 개발 배경

저는 **전문 개발자가 아니라, 반복적인 오피스 업무를 줄이고 싶었던 비즈니스 실무자**입니다.

복잡한 ERP 조회, 월말 결산 폴더 탐색, 반복 이메일 작성처럼 매일 반복되는 단순 업무가 팀의 시간을 소모하는 것을 보며, **어떻게 하면 팀 전체가 더 가치 있는 업무에 집중할 수 있을까**라는 실무적 고민에서 이 프로젝트를 시작했습니다.

실무진의 애로사항과 업무 병목 지점을 직접 분석하며 발전시킨 **SwiftDeck**은 개인용 매크로 스크립트에서 출발해, 반복 업무를 줄이고 팀 업무 방식을 표준화하는 엔터프라이즈급 실무형 오피스 자동화 도구로 확장되었습니다.
